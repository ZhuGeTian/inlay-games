# 行测刷题（0.6.4）

## 开始使用

安装 0.6.4 后，打开任意代码或文本文件，右键或 Tools → 摸鱼合集 → **行测刷题 → 选择试卷**，输入年份或名称筛选。每份试卷独立保存进度；目录同时包含安装包内提供的题库与已导入的题库，同一份不会重复显示。

0.6.4 网站与 GitHub 发行包包含 2026、2025 广东省公务员录用考试行测网友回忆版各 90 题，共 180 题。每份 1–4 题为判断、9–10 题为多选，其余为单选，原题号不变；71–90 题每五题对应一组资料。原 PDF 未附答案正文或解析，故全部保持未知答案，不自动判分或计入错题。只把含公式/图形的题目和图表材料转成原题图，普通题目为注释样式文字。

默认源码构建不包含这些单独管理的题库；仍可通过“导入 JSON 题库”或“打开示例试卷”使用。

示例是本项目原创的功能演示题，含文字题、资料题、图片题和缺答案题，不是粉笔试题。

1. 点击题目中的选项或底部字母按钮，选中的选项标记为 `[B]`。单选题只保留一个选择；判断题仅有 A（正确）、B（错误）；多选题可逐项选中或取消。
2. 点击 **提交**，有答案时才显示对错、答案与解析。多选题必须与完整答案集合一致，少选、多选、错选均判错；无答案则仅记录本次选择。提交后选项锁定；点击 **重做** 后可以重新作答。
3. 整卷模式下，**上一题／下一题** 切换题目；**上一页／下一页** 只翻当前题的材料、选项或解析。长题不会被截掉。
4. **只看错题** 查看曾经答错的题；重做正确后仍保留在错题本，便于重复复习。无错题时可点击 **全部题** 返回。
5. **选择试卷** 切换安装包内或已导入的试卷，每份试卷分别保存当前题号、选择、提交结果和错题记录。
6. **Ctrl+G** 显示／隐藏最近使用的刷题、小说或游戏；macOS 也使用 Control+G。点击其他区域不会收起；显示位置固定，不跟随光标。切换文件后可以通过“在此显示”或隐藏后 Ctrl+G 在新文件显示。
7. 图片在题目中按可用空间缩放；图表文字太小时，右键 **行测刷题 → 查看本题原图**，按原尺寸滚动查看材料、题干和选项图片。
8. **调节显示行数** 输入 1–20，默认 6 行正文（题号和底部按钮另计）。修改立即生效并保存，回到当前题第一页，题号和作答保持不变。正文最多占编辑器可见高度一半；超出内容在整卷模式通过“上一页／下一页”、板块模式通过“上段／下段”查看。图片会适配正文高度，可使用“查看本题原图”放大阅读。
9. **调节刷题字号** 输入 8–32；0 表示跟随 IDE 编辑器字号。主菜单的“调节字号”在刷题模式也控制刷题字号。

**Ctrl+D：隐藏／显示试卷信息和操作栏。** 同时切换顶部的试卷名、题号/题型/页码和完整底部按钮区；隐藏后只显示正文，空出的高度一起收缩。当前题、当前页、作答与正文行数不变，显隐设置自动保存。正文选项仍可点击；右键菜单提供上一页、下一页、提交、重做和前后题。也可从菜单“显示试卷信息和操作栏”恢复。macOS 同样使用 Control+D；快捷键只在当前刷题编辑器启用，整个刷题区收起或切换到小说/游戏后释放。Ctrl+G 仍控制整个刷题区。如自行修改过快捷键，可在 Keymap 搜索该动作调整。

刷题只画在 Inlay 中，不会把题目、选择或答案写入源文件。切换到刷题只隐藏游戏界面，不退出联机房间；切回游戏或小说会隐藏刷题。

重启后恢复最近试卷与答题进度，默认保持隐藏；用 Ctrl+G（刷题是最近模式时）或“在此显示”展开。同一份 JSON 再次导入会恢复原进度；修改 JSON 内容后视为一份新试卷。题内页号不保存，重新显示时从当前题第一页开始。

## 板块练习

先通过“选择试卷”选择年份，再打开 **行测刷题 → 板块练习…**。选择 **言语理解、政治理论、常识** 中一个，仅显示当前试卷该板块；选择 **整卷练习** 返回原来的整卷模式。列表显示实际题量，没有题目的板块不列出。

两份内置广东试卷各有政治理论 10 题（原题号 1–10）、常识 5 题（11–15）、言语理解 15 题（16–30）。其余题目仍可在整卷模式阅读。分类绑定已核对的题库 SHA-256，不根据标题或题干关键词猜测；保留原题号和原题库文件，旧整卷进度不受影响。

- **下一页**：题目 → 答案与解析 → 下一题。可以不选答案直接查看；未选不计错，已选合法选项会在进入答案页时提交。有标准答案才判分，无答案明确提示“未提供答案，暂不判分”。
- **上一页**：按相反顺序返回；第一题题目和最后一题答案处停止，不循环。
- **上段／下段**：当前题目或解析超出显示行数时，逐段阅读；不切换题目与答案。只有多段时才显示按钮，右键也有对应入口。
- **上一题／下一题**：直接切换题目；**重做**清除本次作答并回到题目阶段。只看错题仍限于当前板块。
- 每份试卷的整卷与各板块分别保存进度，切换后恢复题号、题目/答案阶段、选择与错题；题内段号不保存。继续支持 1–20 行、字号、Ctrl+D 隐藏辅助信息和 Ctrl+G 隐藏面板；辅助信息隐藏时通过右键翻页、翻段或切换板块。

**当前两份试卷没有答案解析，板块模式的答案页也不会凭空补写。** 后续导入带 `answer` / `explanation` 的题库即可展示；修改 JSON 后按既有机制视为新试卷。

## PDF 转换流程

把试卷 PDF 和答案解析 PDF 发给 AI，按下面的格式转换成 **UTF-8 JSON**，核对题号、材料、图片和答案对应关系，再通过 **导入 JSON 题库** 选中 JSON 文件。

本版本不直接解析 PDF，不自动联网获取题目。答案或解析不在原文中时留空；不要让 AI 补写未经核实的答案。扫描件、公式、图表需要逐题对照原文核对。内容只保存在本机，不会自动上传到游戏服务器或公开仓库。

## 题库格式

```json
{
  "formatVersion": 1,
  "title": "自制练习",
  "questions": [
    {
      "id": "q001",
      "material": "可选的共享材料；同一材料对应多题时，每题携带同一材料。",
      "materialImages": [],
      "stem": "每天整理 12 份材料，5 天共整理多少份？",
      "images": [],
      "options": [
        {"text": "48 份"},
        {"text": "60 份"},
        {"text": "72 份"},
        {"text": "84 份"}
      ],
      "answer": "B",
      "explanation": "12 × 5 = 60。"
    }
  ]
}
```

| 字段 | 含义 | 要求 |
| --- | --- | --- |
| formatVersion | 文件格式版本 | 数字 1 |
| title | 试卷名称 | 必填，最多 200 字符 |
| questions | 按原试卷顺序排列的题目 | 1–500 道 |
| id | 当前试卷内的题目编号 | 必填且唯一；最多 80 字符，只用英文字母、数字、`_`、`-` |
| type | 题型 | `single` 单选（默认）、`multiple` 多选、`boolean` 判断 |
| section | 板块 | 可选，最多 40 字符；使用 `言语理解`、`政治理论`、`常识`；兼容 `言语理解与表达`、`常识判断`。未知或未填写的自定义题目仅在整卷显示 |
| material | 当前题所需材料 | 可选，最多 40,000 字符 |
| materialImages | 材料中的图表 | 可选，最多 8 张 PNG/JPEG 的纯 Base64 字符串 |
| stem | 题干 | 必填，最多 16,000 字符 |
| images | 题干中的图片 | 可选，最多 8 张 PNG/JPEG 的纯 Base64 字符串 |
| options | A、B、C、D 的选项 | 单选/多选正好四个，判断正好两个；顺序即选项字母 |
| options[].text | 选项文字 | 每项最多 8,000 字符 |
| options[].image | 选项图片 | 可选的 PNG/JPEG 纯 Base64 字符串；与文字至少提供一项 |
| answer | 正确选项 | 单选 `A`/`B`/`C`/`D`；判断 `A`/`B`；多选为 2–4 个不重复字母，例如 `BD`（顺序不限）；未知时省略、null 或空字符串 |
| explanation | 解析 | 可选，最多 40,000 字符；提交后或板块答案页显示 |

图片内嵌，无需额外图片目录。Base64 不包含 `data:image/...;base64,` 前缀；不支持网络链接、文件路径、SVG 或 HTML。单图最多 4 MB／400 万像素，整份题库解码图片最多 1600 万像素（重复的同一 Base64 只计算一次），文件最多 16 MB。

未知答案的题目提交后仅记录选择，提示“未提供答案，暂不判分”，不会记入错题；没有解析时显示“未提供解析”。数据错误或超过限制时拒绝导入，保留原有试卷和进度。

## 本地存储

在目标 IDE 的配置目录内：

- `moyu-practice/papers/<SHA-256>.json`：导入后的题库缓存。
- `options/moyu-practice.xml`：每份试卷的答题进度、错题、模式、字号、显示行数和辅助区显隐。关闭 IDE 后再手动维护这些文件。

题库按原始文件内容计算 SHA-256 身份，因此改排版、改名称或改题目都会产生另一份缓存。没有账户、云同步、倒计时、成绩排名或自动删除功能。

## 构建带指定题库的安装包

转换脚本 `scripts/convert_fenbi_paper.py` 针对本次两份 90 题排版做定位和校验，不是通用 PDF 解析器。需要 pdfplumber 与 Pillow。

```bash
python3 scripts/convert_fenbi_paper.py --pdf /path/to/paper.pdf --year 2026 \
  --output private/practice-banks/practice/papers --audit /tmp/practice-audit
./gradlew :plugin:test :plugin:buildPlugin \
  -PpracticeBanksDir=/absolute/path/to/inlay-games/private/practice-banks
```

目录 `practice/papers/index.json` 是元数据数组，每项包含 `id`（对应 JSON 的 SHA-256）、`title` 和 `questionCount`；文件保存为 `<id>.json`。插件按目录展示，选中时才读取、校验并缓存该卷。

`private/` 已被 Git 忽略。只有显式传入 `practiceBanksDir` 才将指定题库打入包；去掉参数的普通构建会清掉上一次构建遗留的题库资源。0.6.1 已按项目所有者要求将上述两份试卷随网站和 GitHub 发行包提供，原始 PDF 与转换后的独立 JSON 不提交到源码仓库。后续构建需保留该目录，避免升级后内置试卷消失；其他私人题库不自动加入发行包。
