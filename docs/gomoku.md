# 五子棋详细规则

适用版本：0.3.1及0.4.0，规则不变。本项目是15×15、无禁手的自由五子棋，不是围棋，也不采用职业连珠的黑方禁手或交换开局规则。

## 开局与落子

两名真人参加。创建房间者执黑，对应橙色数字1；加入者执白，对应黄色数字2。两人到齐开始，黑先白后，交替在空位落一子。棋子不能移动、覆盖或吃掉其他棋子；每回合只能落一子，没有跳过和悔棋。

数组15行，每行15项，从上到下、从左到右对应棋盘。0是空位。点击空位即可落子；方向键移动下划线，Enter在当前位置落子。服务端检查身份、轮次、位置是否为空和状态版本，不以本地显示直接判定胜负。

## 胜负

任意一方在横、竖、左斜或右斜方向形成**连续五子或更多**即获胜。六连及更长也算胜利；黑方三三、四四、长连均不禁止。中间隔着空位或对方棋子不算连续。

例如同一行`1,1,1,1,1`黑方获胜；`1,1,0,1,1`还没有获胜。棋盘填满且无人形成五连时和棋。对局中认输，或主动退出，判对方胜。结果显示`done=1`黑胜、`done=2`白胜、`done=0`和棋。

## 联机与下一局

临时断线会暂停落子；在同一个项目仍保留身份时可重新连接。隐藏数组不会退出，也不暂停对方。Ctrl+G手动显隐；数组获得键盘操作时Esc也能隐藏。

五子棋当前没有“准备下一局”按钮；结束后退出并重新创建房间。等待时房主退出会移除房间。房间只存在服务端内存中，30分钟无活动过期；服务重启、关闭项目或重启IDE后无法恢复原身份。

顶部`cache: 1/2`表示“我是黑方，目前轮到白方”；`cache: 1/-`表示等待对手；`offline`表示有人离线。字段详解见 [数组说明](array-guide.md)，英文原义见 [词典](glossary.md)。
