# 小说阅读（0.5.1）

阅读功能改编自[missNovel / Novel Inlay0.8.2](https://github.com/datouggg/missNovel)，保留上游Apache2.0许可证。文本以编辑器注释颜色显示在光标上方，只绘制Block Inlay，不修改源码、不进入Git diff。

## 开始阅读

1. 安装摸鱼合集0.5.1并重启IDE，打开代码文件。
2. 右键“摸鱼合集 → 小说 → 导入 TXT 小说”，选择本地TXT；Tools菜单也有相同入口。
3. 点击代码，小说跟随主光标显示。默认每页1行正文加1行进度，默认8秒自动翻页。
4. 使用“我的书架”按书名筛选、切换；每本书分别保留阅读位置。

导入支持UTF-8（含BOM）、带BOM的UTF-16，以及UTF-8失败后的GB18030/GBK回退。原文件和转码后文本均不超过20MiB。编码猜测有歧义，乱码时另存为UTF-8后导入。

## 翻页与显示

小说菜单新增“跟随光标”勾选开关（默认开启，设置会保存）。取消勾选即固定在当前代码位置，点击其他行、翻页、调整行数及Ctrl+G隐藏再显示均保持位置。编辑前面的代码时，小说随原位置自然移动；原位置被删除后，在当前光标重新定位。切换文件也在新文件光标处重新定位。它固定的是文档位置，滚动时会随代码滚动，不是屏幕悬浮窗；IDE重启后首次显示重新定位。重新勾选恢复跟随。

- Ctrl+G显示／隐藏最近使用的内容：阅读小说时控制小说，切回游戏后控制游戏；Mac也是Control+G。
- 小说菜单可单独开关显示。隐藏会停止自动计时，重新开启从原进度继续。
- 点击小说前进一页；右键小说可选上一页／下一页。切换“手动翻段”后只手动翻页。
- 自动翻页间隔可设1～3600秒，显示正文可设1～10行；字体和字号跟随编辑器。
- 只有IDE前台、代码编辑器有焦点、整段显示可见时才累计自动翻页时间。切到终端、打开菜单或切出IDE时停止累计。
- 阅读到末尾停止，不循环从头开始。显示行数和窗口宽度变化会重新排版，保持字符进度。
- 打开小说会隐藏游戏数组，已有房间保持连接；重新显示游戏会隐藏小说。隐藏游戏期间对手和机器人仍可行动。

## 章节、书架和进度

“选择章节”识别独立短行标题，例如第一章、第123回、Chapter1、序章、尾声等；可搜索标题跳转。识别不到章节时仍可正常阅读，自定义目录格式可能需要手动翻页。

每本书按内容SHA-256保存段落和段内位置。相同内容重复导入只缓存一份；不同内容作为不同书。原TXT移动或删除后仍可使用缓存阅读。切换书籍保留各自进度，书架暂不提供删除／重命名。

小说缓存和阅读设置位于IDE配置目录，分别为`inlay-games-novel/books/`和`options/inlay-games-novel.xml`；不写入项目、不参与Settings Sync、不上传游戏服务器。设置在IDE正常保存和退出时落盘，强制结束进程可能回退至上次保存的位置。

这是合集独立的数据目录，**不会自动迁移或改写单独安装的Novel Inlay插件的书架与进度**。已有TXT可重新导入；原插件数据保留。如果两个插件同时显示小说，可在插件设置中禁用原Novel Inlay，避免重复显示。

## 搜索并下载

沿用上游“搜索并下载小说”：按书名关键词及可选的作者完整笔名筛选，至少填写一项，每项最多30字。选择结果后在后台下载，成功才替换当前书；失败或取消保留当前阅读进度。

仅主动搜索或下载时访问第三方奇书网；本地导入、缓存和阅读无需联网，不调用游戏服务。搜索支持GBK字符，作者按全名匹配。上游站点可能限频、返回有限结果或要求验证；遇到验证／改版可从可信来源取得TXT后本地导入。

网络代码限制下载大小、超时和同源跳转，不读取浏览器Cookie或保存登录信息。请使用有权阅读的文本，插件不附送小说正文。自动化测试使用原创样本和本地HTTP服务，不代表第三方书源长期可用。

## 术语

| 名称 | 意思 |
| --- | --- |
| TXT | 纯文本文件 |
| Inlay | 在编辑器行间绘制的内容，不属于源文件 |
| Chapter | 章节，标题识别时支持此格式 |
| SHA-256 | 根据文本内容计算的标识，用来去重和定位进度 |
| UTF-8 / UTF-16 / GBK / GB18030 | 文本字符编码 |

游戏数组词典仍见[英文说明](glossary.md)。小说的代码注释符号`//`仅是显示样式，无需复制或运行。
