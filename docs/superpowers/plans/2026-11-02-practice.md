# 行测刷题 Implementation Plan

> **For agentic workers:** Execute this plan inline using executing-plans, with local checks after each task.

**Goal:** 在摸鱼合集加入本地导入题库和单题刷题能力。
**Architecture:** 新增独立 practice 包：PracticePaper 负责 JSON 校验及图片解码；PracticeProgress 负责答题状态；PracticeSession 负责本地缓存和模式生命周期；PracticeView 负责注释式 Inlay、可点击选项及题内分页；PracticeActions 注册菜单。
**Tech Stack:** Java 17、现有 IntelliJ 232 SDK 与 Gson、Swing/AWT、JUnit4。

### Task 1: 题库与答题模型
- [x] 增加 PracticePaper、PracticeProgress；格式字段和限制详见 docs/practice.md。
- [x] 增加原创 sample-practice.json，验证答案不预先显示、缺答案不判错、重复导入和错题复习。
- [x] 测试非法格式/重复 id/非法答案/非四选项/损坏或过大图片/文件体积；读失败不覆盖现有缓存。

### Task 2: 编辑器集成
- [x] 新增应用服务 PracticeSession：后台读取并原子写入 SHA 缓存，持久化进度，切换试卷恢复，释放编辑器和监听器。
- [x] 新增 PracticeView：固定锚点、主题字体/颜色、文字折行、图片缩放、题内分页和点击区域，操作不修改文档；无可选错题显示空状态和返回全部按钮。
- [x] 新增 PracticeActions；注册 plugin.xml；在 Actions.kt、GomokuSession.kt、NovelReader.java、ReaderStartup.java 接入显示互斥和 Ctrl+G，处理异步导入中切换模式。

### Task 3: 验证和交付
