# 行测刷题模式

用户已确认：先搭建刷题功能，后续提供 PDF，由 AI 转成题库后本地导入。

- Tools/编辑器右键 → 摸鱼合集 → 行测刷题：导入 JSON、打开示例、切换试卷、显示隐藏、上下题、提交、重做、只看错题、字号。
- 一次一道单选题（四个选项），材料、题干、选项支持图片；长内容按编辑器可用宽度折行，并在同一题内分页，不能因高度超出视口而无法操作。
- 默认固定在当前代码行；点其他区域不关闭。Ctrl+G 仅切换最近使用的内容，与游戏、小说互斥显示但不退出房间。字号默认跟随 IDE，可单独设置 8–32。
- 点击选项仅选择，提交后显示结果、答案及解析。未提供答案时只能记录选择并标记“未提供答案”，不判断对错；缺解析时明确提示。
- 每份原始题库的 SHA-256 作为缓存身份，逐题选择和提交、当前题号、错题记录持久化到 IDE 本地配置。错题本保留曾答错的题，正确重做后仍可复习。重新导入同一内容恢复进度，内容修改视为另一份试卷。
- JSON formatVersion=1；最多 500 题，每题 id 唯一、四个选项。PNG/JPEG 图片以 Base64 内嵌，限制文件、文字和解码像素规模。不请求远程资源，不写源代码，导入失败保留当前试卷与进度。
- 原创示例包含文字题、无答案题、材料题和图形题；不预装粉笔内容。不实现直接 PDF 解析、云同步、考试计时或自动发布。
- 用模型测试覆盖非法数据、答案和错题；编辑器集成测试覆盖选择提交、分页、文档零修改、模式切换、Ctrl+G 和序列化；构建新版 0.6.0 本地安装包。
