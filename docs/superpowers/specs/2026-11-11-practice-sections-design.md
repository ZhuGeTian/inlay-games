# 行测板块练习

新增“板块练习…”菜单，在当前试卷中选择言语理解、政治理论、常识；“整卷练习”恢复原模式。两份现有广东题库按原题号分为政治1–10、常识11–15、言语16–30，仅对校验值精确匹配的已发行题库应用，不靠标题或题干关键词猜分类。新导入题库可提供 section 字段。原 JSON/哈希不修改，已有整卷进度保留。

板块使用独立进度：题目页 → 下一页 → 答案页 → 下一页 → 下一题。无需先选答案；选了合法答案时展示答案前提交，未选不计错。答案页只显示答案与解析，有答案则显示，无答案明确提示。末题答案页禁用下一页；上一页按阶段反向返回。题目或解析过长时“上段/下段”只翻当前阶段内容，不改变下一页语义。

每份试卷每个板块保存题号、答案阶段、选择和错题，整卷与各板块隔离。复用1–20行、字号、Ctrl+D、Ctrl+G、固定位置与原图。只看错题仍在所选板块内过滤，空板块不进入。复习已作答题时题目阶段不泄露答案。

缺失答案不补猜，用户若另行授权查证则作为新增内容任务处理。版本0.6.4，通过必要验证后同步服务器和GitHub。
