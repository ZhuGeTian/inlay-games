# 按试卷选择与广东行测题库

用户已指定先使用 2025、2026 广东行测网友回忆版 PDF，两份分别选择、分别记进度。

- 菜单“选择试卷”展示随本地安装包提供的试卷和用户已导入的试卷，按年份标题倒序；同一 SHA 不重复。
- 两份各 90 题，1–4 判断题（A 正确、B 错误），9–10 多选题，其余单选题；多选支持逐项选中/取消和提交，判分要求答案集合完全相同。
- PDF 没有答案正文，仅附扫码入口；不访问二维码、不生成答案，全部保留未提供答案/解析状态。
- 纯文字题提取为文字，含图形/内嵌公式的题用逐题原图裁剪保真；71–90 每五题关联一组共享资料。检查跨页选项和图表边界。
- 通用代码和转换脚本可提交仓库；用户原卷、转换题库、图像与私人索引放 gitignored private/。通过显式 Gradle 参数构建含两份题库的本地安装包，不自动公开这些内容。
- 保留 formatVersion=1 与旧题库兼容，新增 type（single/multiple/boolean，默认 single），所有题型答案缺失时不判分。更新 0.6.1。
