# Ctrl+D 切换刷题辅助信息

按用户截图，Ctrl+D 同时切换顶部试卷名、题号/题型/页码，以及完整底部按钮区。正文、选项、当前题页和作答保持不变；隐藏时删除辅助区占位并按当前页实际内容缩高。Ctrl+G 仍切换整个面板。首次使用显示辅助区，后续持久化选择。

沿用 action + 本地编辑器快捷键注册，在刷题 Inlay 存活期间接管 Ctrl+D；其他编辑器、小说/游戏模式及整个刷题区隐藏时不启用，并释放注册。Mac 使用 Control+D。右键提供显隐菜单及上一页/下一页，隐藏按钮时仍可操作完整题目。

方案采用按需绘制与重新计算坐标，不改源代码、不新建浮窗。测试确认高度、页码、选项命中、隐藏按钮无幽灵点击、显隐持久化、快捷键生命周期及原有 Ctrl+G。发布 0.6.3，保留题库；按约定同步服务器和 GitHub。
