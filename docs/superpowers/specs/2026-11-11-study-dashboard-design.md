# 个人刷题看板

用户已选择：个人登录看板；优先复用服务器现有AI接口。部署 https://zhugetian.com/study/，独立Node22进程及SQLite，不改动/重启游戏进程。

插件从新版开始记录每次成功提交（包括下一页隐式提交），重做为新作答。记录UUID、时间、题库/题号、题目及选项快照、参考答案、分类、结果；不上传代码、项目路径、小说。本机队列先落盘，配置配对码后后台同步，服务按UUID去重；离线重试，撤销设备后停止接受其令牌。旧进度没有时间，不编造历史日期。

统计按北京时间自然日，展示作答次数、独立题数、已判分正确率、未判分数量、每日趋势、板块分布、当日/指定范围作答明细、错题及详情。正确率=正确次数/有确认答案的作答次数，重做分别记录，错题可区分最新已纠正。空数据不显示示例成绩。

密码登录个人看板；服务端会话HttpOnly/SameSite，操作限流及同源校验；配对码短时一次有效，插件只获取上传令牌，无法读全部历史或调用AI。插件凭据放IDE密码库，配对由用户主动完成，发行包无个人令牌。

AI按用户点击生成范围内的学习复盘，输入仅统计及少量错题摘要，保留日期/来源/模型标记；不改答案、不虚构成绩。接口不可用显示真实状态，不把规则统计冒充AI。密钥仅服务端，限频和输出长度约束。可用现有API的前提下做真实小请求验证。

复用现有HTTPS域名，独立systemd低权限进程、SQLite在线备份和恢复核验。完整端点/统计/重复提交/认证隔离/AI失败测试，插件事件与离线同步检查，浏览器验收后部署并发布插件0.7.0到网站/GitHub。官方市场不自动上传。
