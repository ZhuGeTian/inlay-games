# 刷题显示行数

用户要求缩小当前刷题展示区域，并要求未来新增功能支持调节展示区域。

采用正文行数上限，默认 6 行，可设 1–20 行，标题与底部操作区不计入。相比仅调字号，行数可直接控制高度；相比拖拽面板，沿用现有菜单和分页代码，操作一致且无需额外 UI。

菜单：摸鱼合集 → 行测刷题 → 调节显示行数。保存到 moyu-practice.xml，旧配置缺失或越界时回退 6。输入非整数或越界不能提交。修改立即刷新，回到当前题第一页，不更改答案、题号、错题或固定位置。正文高度最多占编辑器可见高度的一半，至少一行；图像按正文空间缩放，仍能查看原图。正文溢出通过上一页/下一页完整访问，底部按钮保持可用。

只改行测刷题；小说已有行数设置，未来新增展示模块必须提供持久化的展示区域设置，并写入 AGENTS.md。版本 0.6.2，沿用两份已发行试卷，必要检查后自动发布服务器和 GitHub；市场单独处理。

检查包括行数缩小时 Inlay 高度下降、逐页读取文本无缺失、图像小区域绘制、按钮点击、非法配置恢复和设置序列化。
