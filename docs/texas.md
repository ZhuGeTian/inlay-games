# 德州好友房

需要三人使用 0.3.0 或更新版本。编辑器右键 **联机小游戏 → 德州 → 创建房间／加入房间**，房主复制房间码给另外两人。默认服务器地址保持不变，插件自动选择 `/gomoku/texas/ws`。

## 牌面与操作

牌面只显示点数：2–10、J、Q、K、A。不画花色图标，以颜色区分：**蓝色黑桃、红色红桃、绿色梅花、橙色方块**。花色不参与牌力比较；手牌、公共牌、摊牌共用映射。背景和字体家族跟随编辑器，字号可调 8–32。

| 显示 | 含义 |
| --- | --- |
| `cache: a/b` | 本人座位／当前行动座位，座位按 1、2、3 顺时针 |
| `phase` | 0 等待，1 翻牌前，2 翻牌，3 转牌，4 河牌；结束时保留所在街 |
| `local` / `shared` | 本人两张底牌／公共牌 |
| `stacks` / `bets` | 三人剩余积分／本轮下注额 |
| `live` | 三人是否在线：1 在线、0 离线 |
| `flags` | 1 未弃牌且未全下、2 全下、-1 弃牌、0 本手未参与 |
| `cursor` / `round` | 庄家座位／第几手 |
| `pool` / `cost` | 当前底池／本人需补的跟注额 |
| `change` / `ref1..3` | 结算净变化／可公开的底牌 |
| `drop()` / `check()` | 弃牌／过牌 |
| `sync(n)` / `set(...)` | 跟注 n／输入加注到的本轮累计额 |
| `flush(n)` / `next()` | 剩余 n 全下／准备下一手 |

当前不能使用的操作会变灰。右键 **德州** 子菜单提供中文操作。加注对话框显示最小和最大累计额、本人本轮已投入额；局面变化后拒绝旧输入，需重新选择。Enter 优先过牌，没有过牌时跟注，不会自动加注或全下。

Ctrl+G 手动显隐（Mac 也是 Control），点击代码区域、切窗、打开对话框不收起。点击代码区会释放游戏键盘操作，再点击数组恢复；数组处于键盘操作状态时 Esc 可收起。隐藏保留连接，游戏内容不写入源码。

## 房间规则

- 三人到齐自动开局，每人 1000 虚拟积分，固定小盲 5／大盲 10，无限注，无抽水或重买。
- 每手轮转庄家，翻牌前从大盲左侧行动，翻牌后从庄家左侧行动。零筹码玩家本手旁观；剩两名有筹码玩家时按单挑规则，庄家下小盲、翻牌前先行动、翻牌后后行动。
- 每人两张底牌；翻牌三张、转牌一张、河牌一张，每街先烧一张牌。从七张中取最佳五张，支持 A2345，花色不打破平局。
- 正常加注增量至少为本街最近一次完整下注／加注增量，至少一个大盲。筹码不足时可短全下；未达到完整加注增量不会重开已行动者的加注权，累计达到才重开。只有一人尚有可下注筹码时仅需补齐实际跟注额，随后自动发完公共牌。
- 按实际投入拆分主池和边池，弃牌者不能赢池；无人跟注的超额退还。各池单独结算，平分零头从庄家左侧顺时针分配。每房总积分始终为 3000。
- 每手结束三人点击 `next()` 后继续。只剩一人有积分时，下一次三人准备会重置为每人 1000。
- 服务端只下发本人底牌及公开信息；摊牌公开未弃牌者底牌。所有对手弃牌而获胜时不公开底牌。
- 任一人临时离线暂停操作，重连可继续。主动退出会关闭整房。30 分钟无操作过期；服务重启、IDE 重启或关闭项目后不能恢复当前身份／对局。没有机器人、观战、行动倒计时或跨房间积分。

下注与结算参考 [Poker TDA 规则](https://www.pokertda.com/view-poker-tda-rules/)，一般牌局流程参考 [Texas Hold’em 规则](https://www.pokerstars.com/poker/games/texas-holdem/)。这是上述固定线上好友房规则，不包含现场赛事裁判流程。

## 一手牌怎样进行

1. 庄家按钮决定座次顺序，小盲投入5、大盲投入10，每人收到两张私有底牌。
2. 翻牌前从大盲左侧开始行动。可以弃牌、跟注或合法加注；已达到当前下注额时可以过牌。大盲面对无人加注也有一次行动机会。
3. 本轮所有尚可行动者完成行动、投入达到要求后，发三张公共牌（翻牌），进行新一轮下注。
4. 再发第四张公共牌（转牌）并下注，再发第五张（河牌）并下注。每次发公共牌前烧一张，不公开。
5. 若任何时刻只剩一个未弃牌玩家，他直接获得底池；否则最终摊牌。从本人两张加公共五张中选最佳五张，允许只用一张甚至完全不用底牌。

全下玩家不再追加，但仍能争夺自己有资格的池。所有下注已完成且没有后续可下注对手时，系统自动补齐公共牌并结算。弃牌后不能重新加入这一手。

## 牌型大小（从大到小）

表格花色仅用于解释；实际界面通过颜色表示。所有比较均只看最佳五张。

| 牌型 | 例子 | 同牌型如何比较 |
| --- | --- | --- |
| 同花顺 Straight flush | 同一花色9、10、J、Q、K | 比最高点；同花10JQKA为最高，俗称皇家同花顺 |
| 四条 Four of a kind | A A A A K | 先比四张主体，再比剩余一张 |
| 葫芦 Full house | Q Q Q 8 8 | 先比三张主体，再比对子 |
| 同花 Flush | 同一花色A、J、9、6、3 | 从最大到最小逐张比较 |
| 顺子 Straight | 8 9 10 J Q | 比最高点；A2345算5高顺子，不能QKA23环绕 |
| 三条 Three of a kind | 8 8 8 A Q | 先比三张主体，再依次比两张踢脚牌 |
| 两对 Two pair | K K 9 9 A | 先比大对，再比小对，最后比踢脚牌 |
| 一对 One pair | J J A 9 4 | 先比对子，再依次比三张踢脚牌 |
| 高牌 High card | A J 9 6 3，不同花且不连 | 从最大到最小逐张比较 |

通常A最大，随后K、Q、J、10到2；仅在A2345顺子中A作1。花色没有高低，完全相同的五张点数组合平分对应底池。比如公共牌已经是A高顺子，且无人能组成更大牌型，双方即使底牌不同也平分；不能拿“第六张牌”打破平局。

## 跟注、加注和全下例子

你本街已投入10，对手加注到30：`sync(20)`再补20，`set(...)`填写的是**本街累计目标**。若要加注到50，实际再扣40，按钮日志记为`raise(50)`。

本街最近一次完整加注增量为20时，下一次完整加注至少再加20。筹码不够可以全下较小的增量，但这种短全下不自动重新开放已行动玩家的加注权；之后累计面对的加注达到完整增量时才重新开放。对话框给出当前合法上下限，以服务端校验为准。没有可跟注的、有剩余积分的对手时，不能继续制造无人可跟的加注。

## 主池、边池、退款与平分

例子：三人本手累计投入分别为100、200、300，且都未弃牌。主池是3×100=300，三人都有资格争夺；边池是2×100=200，只有后两人可争夺；第三人无人跟的额外100退还。第一人即使牌最大，也只能赢主池。弃牌者已经投入的积分仍留在池中，但失去获胜资格。

各池分别比较有资格玩家的最佳五张；可以由不同的人获胜。平分遇到整数零头时，从庄家左侧顺时针给有资格的平局赢家。`change`是结算后的净变化，包含本金返还、分池和退款后的最终盈亏；三人净变化合计为0。

这是虚拟积分好友房；规则以本实现为准，不是现实资金游戏或赛事裁判系统。完整字段及操作见 [数组说明](array-guide.md)，逐词翻译见 [英文词典](glossary.md)。
