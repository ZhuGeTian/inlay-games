# 个人刷题看板

地址：<https://zhugetian.com/study/>。需要个人访问密码，仅供站点所有者使用；公开安装插件不等于能够访问这个看板。

## 开始使用

1. 安装摸鱼合集 0.7.0 或更高版本，重启 IDE。
2. 在网站登录，点“连接插件 → 生成一次性配对码”。配对码10分钟有效、只能使用一次。
3. 在 IDE 的 **Tools → 摸鱼合集 → 行测刷题 → 连接个人看板** 输入配对码。连接后上传本机新版保存的作答记录。
4. 正常选择选项并提交，或选择后点击“下一页”。插件会自动同步；网页点“刷新记录”查看最新数据。
5. 网络不可用时记录保留在本机，每分钟重试；“同步记录／查看状态”可立即重试、查看待同步数量。网页可撤销设备，IDE 可断开连接。

连接令牌由 IDE PasswordSafe 保存，不写入普通设置、插件安装包或 GitHub。首次使用可能由系统弹出钥匙串提示。如果 IDE 密码库仅保存在内存，重启后需重新配对。

## 统计口径

- 时间按 **北京时间** 划分，默认近30天，可查看今天、近7天或一年以内的自定义日期。
- 每次有效提交是一次作答；重做再提交新增一次。翻阅答案、重复点击提交、不选直接看答案不会新增。
- 正确率 = 答对次数 ÷ 有参考答案的作答次数。缺答案只记“未判分”，不推测正确答案。
- 不同题数按题库身份+题号去重；同一题出现在不同试卷中分别计算。重做次数计入作答次数。
- 错题记录保留当时的选择，即使后来答对也不删除，会标记“后来已答对”。详情显示当时题干、选项、参考答案、解析、来源。
- 本版本同步文字与“含图片”标记，题目原图仍在插件中查看。
- 旧版只保存最后选择，没有提交时间；**不能恢复过去每天刷题的日期与次数**。旧版本地错题库和进度继续保留，网站统计从新版开始。
- 记录区和AI分析区可选择展示高度，刷新后保留；超出区域可滚动。

## AI 学习复盘

登录后点击“生成本期分析”，才会向服务端配置的 AI 发送当前范围统计，以及最多12条错题摘要。返回学习概况、可能薄弱点、复习建议；报告保留历史，可再次查看。它不修改题库答案，不把未知答案当错题，不访问代码或小说。

AI 推断不等于结论；样本少时参考价值有限。每次点击会使用所配置服务商的API额度；一分钟内限制重复生成。服务不可用时明确报错，统计和做题继续可用。

当前使用 DeepSeek，接口与模型按 [DeepSeek 官方文档](https://api-docs.deepseek.com/) 配置。密钥只在服务器环境文件，浏览器与插件都不持有。

## 自建部署

服务源码位于 `dashboard/`，使用 Node.js **22.16+** 的内置 SQLite，无额外运行依赖。测试：`cd dashboard && npm test`。

- `/opt/moyu-study/current`：指向当前发布的代码目录。
- `/etc/moyu-study.env`：root权限600，包含下方配置；不要提交或公开。
- `/var/lib/moyu-study/study.sqlite`：个人数据库，目录700；WAL模式。
- `moyu-study.service`：独立用户运行，仅监听127.0.0.1:3107，不依赖游戏进程。
- nginx仅代理`/study/`，HTTP跳转HTTPS；部署模板见`dashboard/deploy/`。

环境变量：

| 名称 | 含义 |
| --- | --- |
| STUDY_DB | SQLite数据库绝对路径 |
| STUDY_PORT | 本地监听端口，默认3107 |
| STUDY_ORIGIN | 允许网页提交的来源，当前https://zhugetian.com |
| STUDY_PASSWORD_HASH | `passwordHash()`生成的salt:scrypt哈希，不填明文密码 |
| AI_BASE_URL | 服务商API基地址，例如https://api.deepseek.com |
| AI_MODEL | 服务商支持的模型，例如deepseek-flash |
| AI_API_KEY | 服务端API密钥 |

通过 `dashboard/server.mjs` 导出的 `passwordHash()` 创建访问密码哈希，应通过标准输入或受保护文件传入密码，不在命令行历史中直接写密码。更换密码后应清空数据库 sessions 表使旧登录失效，再重启看板服务；设备凭证可在网页单独撤销。

配对码只兑换设备上传权限，不赋予查询记录、生成分析或读取其他凭证的权限。会话和设备凭证在数据库中均以SHA-256存储，页面使用HttpOnly/Secure/SameSite cookie及同源校验。只有可信的个人设备可以配对；作答参考答案来自设备题库，不能作为防作弊成绩系统。

当前发布版插件连接本站固定地址。开源自建时修改 `PracticeSync.URL` 后自行构建；网站不提供公开注册或多人账户。

## 备份与恢复

使用 SQLite 在线备份，**不要单独复制正在运行的 .sqlite 文件而忽略 WAL**。例如在服务目录运行（目标目录需由服务用户可写）：

```sh
sudo -u moyu-study env STUDY_DB=/var/lib/moyu-study/study.sqlite \
  node /opt/moyu-study/current/backup.mjs /var/lib/moyu-study/backup.sqlite
```

备份包含私密记录及凭证哈希，权限600，离线妥善保管。本次部署执行了一次在线备份与独立恢复校验；没有配置定时备份或异地备份。

恢复时先停止 **moyu-study**，保留当前数据库及WAL/SHM整套文件，再把已校验的备份安装为`study.sqlite`，所有者moyu-study、权限600，启动并检查`/study/api/health`。不要动游戏服务。发布代码回滚只切换`/opt/moyu-study/current`并重启看板，不覆盖作答数据库。
