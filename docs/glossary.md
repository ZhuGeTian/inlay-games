# 界面英文逐词对照

适用版本：0.4.0。这是游戏界面的词典；数值范围、数组顺序和完整例子见 [数组说明](array-guide.md)。这些代码式文字只是显示，不会执行或写入源码。相同词在不同游戏中可能有不同含义。

## 通用文字与语法

| 单词／符号 | 字面意思 | 在插件里怎么看 |
| --- | --- | --- |
| Inlay | 嵌入、嵌在行间 | 游戏显示在编辑器代码行之间 |
| Games | 游戏（复数） | 插件包含三种游戏 |
| `val` | value，值 | 引出一个显示字段，不需要输入或执行 |
| `arrayOf` | 由这些元素组成数组 | 括号中的每一项是一张牌或一行棋盘 |
| `intArrayOf` | 整数数组 | 一组整数，例如各座位的余牌数 |
| `longArrayOf` | 长整数数组 | 积分等数值数组 |
| `/* ... */`、`//` | 注释 | 顶部状态、底部动作记录 |
| `=`、`,`、`;` | 等于、分隔项、分隔语句 | 只帮助阅读字段和值 |
| `()` | 函数调用的括号 | 橙色可点击文字是操作按钮；注释中的调用样式是动作记录 |
| Ctrl / Control | 控制键 | Ctrl+G 显示／隐藏；Mac也用Control，不是Command |
| Enter | 回车 | 五子棋落子、斗地主出牌、德州优先过牌否则跟注 |
| Esc / Escape | 退出键 | 游戏获得键盘操作时收起数组 |

## 状态与数组

| 单词 | 字面意思 | 游戏里的实际含义 |
| --- | --- | --- |
| `cache` | 缓存 | 顶部`cache: a/b`是本人／行动座位；斗地主`val cache`才是本人手牌；五子棋数组是棋盘 |
| `phase` | 阶段 | 斗地主0等待、1叫分、2出牌、3结束；德州0等待、1翻牌前、2翻牌、3转牌、4河牌，结束保留最后阶段 |
| `owner` | 所有者 | 斗地主地主座位，0尚未确定 |
| `round` | 轮、局 | 斗地主第几次发牌（全不叫重发也增加）；德州第几手 |
| `sizes` | 大小／数量（复数） | 斗地主1、2、3号的剩余牌数 |
| `live` | 在线、活跃 | 各座位在线状态：1在线、0不在线；正常机器人算在线 |
| `auto` | automatic，自动 | 斗地主／德州各座位是否机器人：1机器人、0真人；有机器人时才显示 |
| `bids` | 叫价／竞价记录 | 斗地主各座位叫分：-1未叫、0不叫、1～3分 |
| `seed` | 种子 | 斗地主公开的三张底牌记录，不是地主当前剩余的底牌 |
| `delta` | 差值／变化量 | 斗地主当前保留、需要压过的那手牌；重新领出时为空 |
| `source` | 来源 | `delta`是谁出的，0没有当前牌；不是源码文件 |
| `skip` | 跳过 | 斗地主连续不出次数；与可点击的`skip()`区分 |
| `base` | 基础 | 斗地主当前最高叫分／本局基础分 |
| `factor` | 因子、倍数 | 斗地主炸弹、王炸及春天产生的累计倍数 |
| `score` | 分数 | 斗地主各座位在本房间累计虚拟积分 |
| `winner` | 获胜者 | 斗地主获胜阵营的代表座位；等于owner为地主胜，否则两位农民一起胜 |
| `change` | 变化 | 刚结束一局／一手，各座位净增减的虚拟积分 |
| `ready` | 准备好 | 各座位是否准备下一局：1已准备、0未准备 |
| `local` | 本地、自己的 | 德州本人的两张底牌 |
| `shared` | 共享的 | 德州公共牌，由所有玩家共用 |
| `stacks` | 一叠叠筹码 | 德州各座位尚未投入的剩余虚拟积分 |
| `bets` | 下注（复数） | 德州当前街各座位的累计投入，不是整手累计 |
| `flags` | 标记 | 德州0未参与、1未弃牌且未全下、2全下、-1弃牌；1不表示现在轮到此人 |
| `cursor` | 光标／指针 | 德州庄家按钮的座位，不是当前行动者 |
| `pool` | 池 | 德州未结算总底池，含主池和边池；结算后为0 |
| `cost` | 成本 | 德州本人跟注还需补多少，上限为本人剩余积分 |
| `ref1` / `ref2` / `ref3` | reference，引用／参考 | 德州结算时可公开的对应座位底牌；不是所有人都一定亮牌 |
| `done` | 完成 | 五子棋结局：done=1黑胜、2白胜、0和棋 |
| `offline` | 离线 | 五子棋有人断线，暂停落子 |

三人状态数组固定按1、2、3号排列。`live=[1,1,1]`只说明三座位在线；斗地主和德州看`auto`才能区分真人与机器人。

## 按钮和动作记录

| 单词／形式 | 字面意思 | 实际作用 |
| --- | --- | --- |
| `init()` | initialize，初始化 | 斗地主／德州由房主开始，用机器人补齐空位 |
| `bid(n)` | 叫价 | 斗地主叫n分；0是不叫 |
| `commit()` | 提交 | 斗地主打出所有选中的牌 |
| `skip()` | 跳过 | 斗地主不出；自己领出时不能用 |
| `clear()` | 清空 | 只取消选牌，不丢掉手牌 |
| `next()` | 下一个 | 准备下一局／下一手，不是立刻强制开局 |
| `deal()` | 发牌 | 斗地主底部记录：刚发牌或重发 |
| `play(...)` | 打出、玩 | 斗地主动作记录：某座位打出括号里的牌 |
| `pass()` | 让过 | 斗地主动作记录：不出 |
| `ready()` | 准备 | 斗地主动作记录：某座位已准备 |
| `resign()` | 认输 | 斗地主动作记录：认输；农民认输影响整个农民阵营 |
| `drop()` | 丢弃 | 德州弃牌，放弃本手底池 |
| `check()` | 检查；扑克中为过牌 | 德州无需补注时过牌，保留争夺底池资格 |
| `sync(n)` | synchronize，同步 | 德州跟注，本次再投入n |
| `set(...)` | 设置 | 德州加注输入框，填写本街累计投入要到多少 |
| `flush(n)` | 刷出／清空 | **这个按钮表示全下剩余n，绝不是“同花”操作** |
| `reset(1000)` | 重置 | 德州只剩一人有积分后，下一手全员恢复1000；出现在提示注释里 |
| `raise(n)` | 加注 | 德州动作记录：行动后本街累计投入n |
| `call(n)` | 跟注 | 德州动作记录：行动后本街累计投入n，与按钮sync(n)的本次追加额不同 |
| `allin(n)` | all-in，全部投入 | 德州动作记录：全下后本街累计投入n |
| `fold(n)` | 弃牌 | 德州动作记录；n是当时本街已经投入的数，不再扣一次 |

`check(n)`动作记录中的n也只是当时已投入额。按钮橙色可操作，灰色不可用；动作记录是历史提示，不能点击执行。德州牌的橙色另表示方块。

## 扑克牌与规则常用英语

| 英文 | 中文 | 说明 |
| --- | --- | --- |
| J / Jack | 杰克、J | 点数在10和Q之间 |
| Q / Queen | 王后、Q | 点数在J和K之间 |
| K / King | 国王、K | 点数在Q和A之间 |
| A / Ace | A、尖 | 斗地主低于2；德州通常最大，也可在A2345中作1 |
| Xiao / Da | 小／大（拼音） | 小王／大王，仅斗地主使用 |
| spades / hearts / clubs / diamonds | 黑桃／红桃／梅花／方块 | 德州依次用蓝／红／绿／橙表示 |
| waiting / bidding / playing / finished | 等待／叫分／对局中／结束 | 规则和协议中使用的阶段词 |
| preflop / flop / turn / river | 翻牌前／翻牌／转牌／河牌 | 德州四个下注阶段；turn也可泛指行动轮次 |
| dealer / button | 庄家／庄家按钮 | 决定盲注和行动顺序，不代表庄家有特殊牌力 |
| small blind / big blind | 小盲／大盲 | 发牌时强制投入，本项目5／10 |
| pot / side pot | 底池／边池 | 玩家投入的积分池／全下导致的分层池 |
| showdown | 摊牌 | 比较最佳五张牌并分池 |
| kicker | 踢脚牌 | 主体相同后用于比较的剩余高牌 |
| straight / flush | 顺子／同花 | 此处是牌型；界面flush()按钮另指全下 |
| full house / four of a kind | 葫芦／四条 | 三张相同加一对／四张相同 |
| straight flush | 同花顺 | 同一花色连续五张，含最高的皇家同花顺 |
| no-limit | 无限注 | 合法行动时可投入全部剩余积分，仍受最小加注和加注权约束 |

完整玩法：[五子棋](gomoku.md) · [斗地主](doudizhu.md) · [德州](texas.md)。
